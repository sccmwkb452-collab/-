# DEMO на Vercel

Vercel раздаёт Mini App и админ-панель как статические сайты. Весь API (и бот, если задан токен) работает в одной функции Python — `api/index.py`. База — PostgreSQL от Neon, подключается из Vercel Marketplace. Демо открывается в обычном браузере: каждый посетитель получает свой анонимный аккаунт. Оплата тестовая, Stars не отправляются.

> Vercel подходит для демонстрации. Для настоящих продаж разверните магазин на VPS по [DEPLOY.md](DEPLOY.md): там есть отдельный воркер, Redis и бэкапы. Тариф Hobby у Vercel — только для некоммерческого использования.

## Запуск

1. Войдите на [vercel.com](https://vercel.com) через GitHub. Нажмите **Add New → Project** и импортируйте репозиторий `sccmwkb452-collab/-`. Если его нет в списке, нажмите **Configure GitHub App** и дайте доступ к репозиторию.
2. Задайте **Project Name**, например `pulsar-demo`. В **Root Directory** нажмите **Edit** и выберите папку `stars-shop`. Остальные настройки возьмутся из `vercel.json`. Нажмите **Deploy**. Сборка пройдёт, но API будет отвечать «База данных недоступна»: базы ещё нет.
3. Откройте **Storage → Create Database → Neon** (Serverless Postgres). Выберите регион **Frankfurt (aws-eu-central-1)**: функция работает там же (`fra1`). Затем нажмите **Connect** и подключите базу к проекту во всех окружениях. Vercel добавит переменные `DATABASE_URL`, `DATABASE_URL_UNPOOLED` и другие.
4. Рекомендуется: в **Settings → Environment Variables** добавьте `SECRET_KEY` — 64 случайных символа (`openssl rand -hex 32`). Без него ключ выводится из пароля базы.
5. В **Deployments** откройте последний деплой и нажмите **Redeploy**: переменные окружения применяются только к новым деплоям.
6. Откройте `https://<имя-проекта>.vercel.app`. Первый запрос создаст таблицы и DEMO-каталог, это займёт несколько секунд.

С компьютера то же самое делается из консоли:

```bash
cd stars-shop
npx vercel@latest link           # создать проект; Root Directory — эта папка
npx vercel@latest deploy --prod  # базу Neon подключите в панели Vercel (шаг 3)
```

## Как это устроено

* `vercel.json` описывает сборку `deploy/vercel/build.sh`: Mini App попадает в корень `dist/`, админка — в `dist/admin/`. Там же заданы маршруты SPA, заголовки безопасности (те же, что в nginx) и регион функции.
* Функция: `api/index.py`, зависимости `api/requirements.txt` (версии совпадают с `backend/requirements.txt`, это проверяет тест), Python 3.12 из `api/.python-version`. Код берётся из `backend/`, связку с Vercel делает `starshop/serverless.py`.
* Первый запрос каждого экземпляра функции готовит базу: применяет миграции под advisory-блокировкой, в новой базе создаёт DEMO-каталог, заводит администраторов из `ADMIN_TELEGRAM_IDS`. Всё это идёт одной транзакцией, поэтому одновременный старт нескольких экземпляров безопасен. Если база недоступна, API отвечает 503 «База данных недоступна» и повторяет попытку на следующем запросе.
* Воркера нет. Доставка, уведомления, возвраты и отмена неоплаченных заказов выполняются после ответов API (`worker/inline.py`). После оплаты доставка запускается сразу, остальное — не чаще заданного интервала.
* Пула соединений нет: на Vercel экземпляр функции может «замереть» между запросами, поэтому каждый запрос открывает своё соединение. Используется прямое подключение Neon (`DATABASE_URL_UNPOOLED`).

## Переменные окружения

Все переменные необязательны, кроме базы. Явно заданное значение всегда важнее значения по умолчанию.

| Переменная | По умолчанию на Vercel | Что делает |
| --- | --- | --- |
| `DATABASE_URL_UNPOOLED`, `DATABASE_URL` | задаёт Neon | Подключение к базе. Порядок выбора: `DATABASE_URL_UNPOOLED` → `POSTGRES_URL_NON_POOLING` → `DATABASE_URL` → `POSTGRES_URL`. Если при подключении Neon вы указали префикс переменных, задайте `DATABASE_URL` вручную |
| `SECRET_KEY` | выводится из адреса базы | подписи CSRF, DEMO-платежей и демо-аккаунтов |
| `PUBLIC_BASE_URL` | `https://` + основной домен проекта | ссылки в боте и на Mini App |
| `APP_ENV`, `APP_MODE` | `production`, `demo` | `/api/docs` и dev-вход выключены; включить PRODUCTION нельзя, пока не задан `ALLOW_PRODUCTION` |
| `PAYMENT_PROVIDERS`, `DELIVERY_PROVIDER` | `demo`, `demo` | тестовая оплата, Stars не отправляются |
| `PUBLIC_DEMO` | `true` | демо-аккаунты для посетителей из браузера; `false` — магазин работает только из Telegram |
| `INLINE_WORKER`, `AUTO_MIGRATE`, `DATABASE_POOL_SIZE` | `true`, `true`, `0` | фоновые задачи после запросов, подготовка базы, работа без пула |
| `ADMIN_TELEGRAM_IDS` | — | ваш Telegram ID (узнать можно у @userinfobot): владелец админки |
| `BOT_TOKEN`, `BOT_USERNAME` | — | бот на вебхуке, см. ниже |
| `BOT_MODE` | `webhook` | `polling` — бот запущен в другом месте, Vercel не трогает вебхук |
| `BOT_WEBHOOK_SECRET` | выводится из `SECRET_KEY` | секрет заголовка вебхука Telegram |
| `REDIS_URL` | — | Upstash Redis из Marketplace: общие лимиты запросов и диалоги бота |

## Демо-аккаунты в браузере

Браузер посетителя хранит случайный ключ и отправляет его в заголовке `Authorization: demo <ключ>`. Сервер получает из ключа ID пользователя через HMAC с `SECRET_KEY`, поэтому выбрать чужой ID нельзя. Посетитель видит только свои заказы, а после перезагрузки остаётся тем же пользователем.

Такие ID начинаются с 2⁵² — это больше любого Telegram ID (в них не больше 52 значащих бит), так что демо-посетитель не может оказаться настоящим пользователем Telegram. Админ-панель принимает только данные, подписанные Telegram. Сообщения в Telegram демо-посетителям не ставятся в очередь. В режиме PRODUCTION демо-аккаунты отключаются (код `demo_identity_disabled`).

## Бот

Необязательно, но тогда работает всё: `/start`, Mini App внутри Telegram, вход в админку командой `/admin` и уведомления.

1. Создайте бота: @BotFather → `/newbot`.
2. В Vercel задайте `BOT_TOKEN`, `BOT_USERNAME` (без @) и `ADMIN_TELEGRAM_IDS`, затем сделайте **Redeploy**.
3. Откройте сайт один раз. Сервер сам зарегистрирует вебхук `https://<домен>/api/v1/webhooks/telegram` с секретом, команды бота и кнопку меню «Магазин» с Mini App. Если Telegram был недоступен, сервер повторит попытку через 5 минут.
4. Напишите боту `/start`. Команда `/admin` пришлёт одноразовую ссылку в админку.

Диалог с поддержкой в боте хранит состояние в памяти экземпляра функции. Чтобы оно не терялось, подключите Upstash Redis (`REDIS_URL`).

## Вход в админку

* **Через бота:** команда `/admin`.
* **Через Telegram Login Widget:** в @BotFather выполните `/setdomain` с доменом проекта. На странице `/admin/` появится кнопка «Войти через Telegram». Войти могут ID из `ADMIN_TELEGRAM_IDS` и администраторы, добавленные в панели.
* **С компьютера:** в `backend/` (окружение из README) выполните
  `DATABASE_URL='<адрес Neon>' PUBLIC_BASE_URL=https://<домен> .venv/bin/python -m starshop.cli admin-link <ваш Telegram ID>`.

## Ограничения

* Фоновые задачи выполняются, только пока к сайту приходят запросы. Заказ доставляется сразу после оплаты, а уведомления в Telegram и отмена просроченных заказов ждут следующего запроса.
* Режим Fluid compute (у новых проектов он включён по умолчанию) даёт фоновым задачам доработать после ответа. Без него экземпляр может «замереть» посреди задачи. Тогда задача продолжится позже, а зависшую доставку подберёт восстановление.
* Лимиты запросов считаются отдельно в каждом экземпляре функции. Общий счётчик даёт `REDIS_URL`.
* Соединение с базой открывается на каждый запрос. Функция и база должны быть в одном регионе (`fra1` и Frankfurt).
* Первый запрос после простоя медленнее (холодный старт — 1–3 с). Бесплатная база Neon засыпает после 5 минут без запросов и просыпается примерно за полсекунды.

## Что проверено

* `vercel build` (Vercel CLI 65.2) локально: сборка обоих фронтендов, функция на Python 3.12, бандл около 66 МБ.
* Собранная функция запущена через рантайм Vercel (`vercel_runtime`, вызов как в AWS Lambda) с новой базой PostgreSQL по TLS. Проверены:
  * на первом запросе — миграции, каталог и владелец;
  * в браузере (Playwright) — покупка до «Выполнен» менее чем за секунду после оплаты и Lucky Buy с проверкой честности;
  * разные демо-аккаунты у разных браузеров, вход в админку по одноразовой ссылке, отсутствие нарушений CSP;
  * при недоступном Telegram сайт работает.
* **Не проверено:** настоящий деплой на Vercel, база Neon и бот с настоящим токеном. Из среды разработки не было доступа к vercel.com и neon.tech.
