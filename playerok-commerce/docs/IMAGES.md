# Генератор изображений

Картинки для объявлений строятся из ваших шаблонов: генератор стирает старые надписи (число, номинал, слово) и пишет новые тем же шрифтом, размером и в том же месте. Оригиналы не изменяются — результат сохраняется в `backend/storage/images/`.

## Ваши шаблоны

Разметка для пяти присланных шаблонов уже готова в `backend/assets/templates/originals/*.json`. Нужны сами файлы изображений — положите их в эту папку под такими именами:

| Файл | Что меняется | Категория |
| --- | --- | --- |
| `tg-premium.png` | «3 месяца» → «6 месяцев», «12 месяцев» | Telegram Premium |
| `tg-stars.png` | число и слово «звёзд» (со склонением) | Telegram Stars |
| `tg-subscribers.png` | число на плашке | Продвижение в Telegram |
| `pubg-uc.png` | число UC | PUBG Mobile UC |
| `steam-giftcard.png` | номинал («5$») | Steam Gift Cards |

После этого: веб-панель → «Генератор изображений» → «Обновить шаблоны» (или раздел «🖼» в боте). Шаблон без файла отображается как «Ждёт файл изображения».

Изображения, присланные в чат с Claude, не попадают на диск сервера автоматически — их нужно загрузить в репозиторий (папка выше) или скопировать на сервер (`docker compose cp`, затем пересборка образа или `update.sh`).

## Как это работает

1. **Калибровка.** Генератор находит в исходной надписи первый символ (по пустому промежутку между столбцами пикселей), измеряет его высоту, левый край и базовую линию — новая надпись рисуется в том же масштабе и на той же линии.
2. **Стирание.** Светлые пиксели надписи в заданной области заменяются фоном, восстановленным из окружения (нормированная свёртка по маске): на градиентах следов не видно. Плашки перерисовываются целиком градиентом, снятым с оригинала.
3. **Текст.** Шрифты Unbounded и Montserrat (лицензия OFL, файлы в `backend/assets/fonts`), автоматический перенос и уменьшение до `min_size`; тень и объём — если заданы в разметке. Эмодзи и символы, которых нет в шрифте, отбрасываются.

## Формат разметки

Координаты — доли ширины и высоты (`"units": "relative"`), поэтому разметка подходит к любому размеру экспорта.

```json
{
  "name": "Telegram Stars (ваш шаблон)",
  "units": "relative",
  "groups": ["telegram"],
  "categories": ["tg_stars"],
  "erase": [
    { "box": [0.035, 0.51, 0.56, 0.185], "mode": "text", "min_brightness": 205, "max_saturation": 70 }
  ],
  "fields": [
    {
      "name": "amount",
      "template": "{amount}",
      "box": [0.055, 0.40, 0.55, 0.28],
      "font": "Unbounded-VF.ttf:Bold",
      "size": 0.1917,
      "min_size": 0.09,
      "valign": "baseline",
      "max_lines": 1,
      "calibrate": { "erase": 0, "glyph": "0" }
    }
  ]
}
```

| Ключ | Значение |
| --- | --- |
| `categories` / `groups` | Для каких категорий шаблон выбирается автоматически (товар может указать свой шаблон явно) |
| `erase[].mode` | `text` — стереть светлые буквы; `fill` — залить область фоном; `pill` — перерисовать плашку (`sample_top`, `sample_bottom` — точки для градиента) |
| `fields[].template` | Текст с переменными: `{amount}`, `{amount_word}`, `{face_short}`, `{title}`, `{nominal}`, `{region}`, `{subtitle}`, `{price}`, `{category}` |
| `size`, `min_size` | Размер шрифта как доля высоты изображения |
| `valign` | `top`, `middle`, `bottom` или `baseline` (по измеренной базовой линии) |
| `calibrate` | Какую область стирания измерить и по какому символу |
| `shadow`, `extrude` | Тень и объёмный эффект |

Демо-шаблоны (`backend/assets/templates/demo`) используются, пока ваших файлов нет.
