# Шаблоны изображений владельца

Сюда кладутся **оригиналы** шаблонов (PNG/JPG/WebP). Система их не изменяет: файл
открывается только на чтение, генерация идёт в памяти, результат сохраняется в
`backend/storage/images/`.

Разметка уже подготовлена (JSON рядом с картинкой, координаты — доли размера, поэтому
подходит любой экспорт). Положите файлы с такими именами:

| Файл | Что меняется | Категории |
| --- | --- | --- |
| `tg-premium.png` | «3 месяца» → «6 месяцев», «12 месяцев» | Telegram Premium |
| `tg-stars.png` | «50» и «звёзд» (склонение) | Telegram Stars |
| `tg-subscribers.png` | число на плашке («5000») | Продвижение в Telegram |
| `pubg-uc.png` | число UC | PUBG Mobile UC |
| `steam-giftcard.png` | номинал («5$») | Steam Gift Cards |

Как это работает:

1. Старый текст стирается: светлые пиксели надписи в заданной области заменяются
   фоном, достроенным из окружения (на размытых градиентах это незаметно).
   Если у вас есть версии без текста (фон из Figma/PSD), положите их под теми же
   именами — разметка подойдёт, а качество будет идеальным.
2. Перед стиранием генератор **измеряет исходную надпись** (левый край, высоту первого
   символа, базовую линию) и рисует новую тем же размером и в том же месте.
3. Шрифт — Unbounded (OFL), он совпадает со шрифтом шаблонов; для плашки «5000» —
   Montserrat ExtraBold с объёмной тенью.

После добавления файлов: «🖼 Генератор изображений» в боте (реестр обновится сам) или
`POST /api/v1/images/templates/sync`. Шаблон без файла показывается как «ждёт файл»,
файл без разметки — как «нужна разметка полей».

Логотипы брендов (Telegram, PUBG Mobile, Steam) и подпись «Playerok» в шаблонах —
ваши материалы; система их не добавляет и не изменяет.
