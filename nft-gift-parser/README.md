# NFT Gift Parser

Простой парсер NFT-подарков Telegram. Читает публичные страницы
`https://t.me/nft/<Коллекция>-<номер>`. API-ключи, аккаунт и Telethon не нужны.

С каждой страницы берёт:

- название и картинку подарка;
- модель, фон и символ вместе с редкостью (в %);
- владельца (имя и ссылку, если профиль публичный);
- сколько выпущено и сколько всего в коллекции.

## Установка

```bash
cd nft-gift-parser
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Использование

```bash
# Один подарок (ссылку можно писать полностью или коротко)
python -m gift_parser https://t.me/nft/PlushPepe-1
python -m gift_parser PlushPepe-1 DurovsCap-42

# Диапазон номеров -> CSV
python -m gift_parser PlushPepe --from 1 --to 200 -o pepe.csv

# Вся коллекция (размер берётся со страницы первого подарка) -> JSON
python -m gift_parser PlushPepe -o pepe.json

# Фильтры: модель/фон/символ (подстрока) и редкость
python -m gift_parser PlushPepe --to 500 --model Pumpkin
python -m gift_parser PlushPepe --max-rarity 0.5 -o rare.csv
```

| Флаг | Значение |
|------|----------|
| `--from` / `--to` | диапазон номеров (по умолчанию от 1 до конца коллекции) |
| `-o file.csv` / `-o file.json` | формат выбирается по расширению файла |
| `--format table\|json\|csv` | формат вывода в консоль |
| `-c 5` | сколько запросов идёт параллельно |
| `--delay 0.2` | пауза после каждого запроса, в секундах |
| `--proxy http://host:port` | HTTP-прокси |
| `--lang ru` | язык страниц (поддерживаются en и ru) |

На ответ 429 парсер ждёт `Retry-After` и повторяет запрос. Сетевые ошибки
повторяются до 3 раз. Несуществующие номера пропускаются.

## Telegram-бот

Самый простой запуск: дважды кликнуть `run_bot.bat` (Windows) или выполнить `./run_bot.sh` (Mac/Linux). Скрипт сам поставит зависимости и спросит токен.

Или вручную:

```bash
BOT_TOKEN=123456:ABC... python bot.py
```

| Переменная | Значение |
|------------|----------|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_IDS` | ID админов через запятую, по умолчанию `8644082658` |
| `DB_PATH` | файл базы SQLite, по умолчанию `gifts.db` |
| `PARSE_CONCURRENCY` | сколько страниц парсить параллельно, по умолчанию 5 |
| `PARSE_PROXY` | HTTP-прокси для запросов к t.me |

### Для пользователя

`/start` → **🔍 Парсинг** → коллекция → модель → список всех NFT этой модели
(номер, владелец со ссылкой, фон и символ) по 15 на страницу. Кнопка
**📥 Скачать списком (TXT)** присылает весь список модели файлом. Если в базе одна
коллекция, бот сразу показывает её модели.

### Админ-панель (`/admin`)

- **📥 Загрузить базу (TXT)** — пришли `.txt`, по одной записи в строке:

  ```
  https://t.me/nft/PlushPepe-1     один подарок (можно несколько ссылок в строке)
  PlushPepe-1                      то же самое
  PlushPepe 1 500                  номера 1–500 (или PlushPepe 1-500)
  PlushPepe                        вся коллекция
  # строки с # пропускаются
  ```

  Бот парсит в фоне, раз в 5 секунд обновляет прогресс, его можно остановить
  кнопкой. Подарки раскладываются по моделям; повторная загрузка обновляет данные.
- **🗑 Очистить базу** — удалить все NFT (пользователи и каналы остаются).
- **📊 Статистика** — пользователи (всего, активные, заблокировавшие бота, новые
  за сутки и неделю), NFT, коллекции, модели, дата последней загрузки.
- **📢 Рассылка** — любое сообщение (текст, фото, видео) копируется всем
  пользователям; перед отправкой показывается превью. Кто заблокировал бота,
  помечается и больше не получает рассылки.
- **🔒 Обязательная подписка** — добавить канал (`@username`, ссылка, пересланный пост
  или `-100… https://t.me/+invite` для приватного) и удалить его. Бот должен быть
  админом канала. Пока пользователь не подписан на все каналы, бот показывает
  только кнопки подписки и «✅ Я подписался».

### Сервер 24/7

Нужен любой VPS с Ubuntu 22.04/24.04 (хватит 1 vCPU и 1 ГБ RAM). Залей на него
папку `nft-gift-parser` и выполни в ней:

```bash
sudo BOT_TOKEN=123456:ABC... bash deploy/install.sh
```

Скрипт ставит Python, зависимости и systemd-сервис `nft-gift-bot`. Бот
перезапускается сам при падении и после перезагрузки сервера. База лежит в
`/opt/nft-gift-bot/data/gifts.db`, токен в `/etc/nft-gift-bot.env` (доступ только root).
Чтобы обновить код, залей новую папку и запусти скрипт ещё раз, уже без
`BOT_TOKEN`: база и токен сохранятся.

```bash
journalctl -u nft-gift-bot -f        # логи
sudo systemctl restart nft-gift-bot  # перезапуск
```

## Использование из кода

```python
import asyncio
from gift_parser import GiftParser

async def main():
    async with GiftParser(concurrency=5) as p:
        gift = await p.get_gift("PlushPepe", 1)
        print(gift.model, gift.owner_name)
        async for g in p.get_collection("PlushPepe", 1, 100):
            print(g.number, g.backdrop)

asyncio.run(main())
```
